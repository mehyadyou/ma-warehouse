# راهنمای نصب اپ «انبار MA» روی گوشی (اندروید)

> نسخه ۱.۱.۰ به بعد با امضای رسمی منتشر می‌شود. اگر نسخهٔ قدیمی (`ma_app` با آیکون پیش‌فرض)
> روی گوشی هست، **اول آن را حذف (Uninstall) کنید** — چون امضا عوض شده، نصب روی نسخهٔ قبلی
> با خطای «signatures do not match» شکست می‌خورد.

## نصب قدم‌به‌قدم

1. فایل `app-release.apk` را به گوشی منتقل کنید (کابل USB / بلوتوث / دانلود از لینک مدیر).
2. روی فایل بزنید → اندروید می‌پرسد «Install unknown apps» — برای همان برنامه (مثلاً Files
   یا Chrome) گزینه **Allow from this source** را روشن کنید و برگردید.
3. **Install** را بزنید. اگر Play Protect هشدار داد («Unknown app»)، روی **Install anyway**
   (یا Details ← Install anyway) بزنید — این هشدار برای همهٔ اپ‌های خارج از Play Store
   طبیعی است و با امضای رسمی ما کم‌رنگ‌تر از قبل است.
4. بعد از نصب، اپ را باز کنید. آیکون و نام جدید: **«انبار MA»**.
5. ورود با همان شماره و رمز همیشگی. اینترنت گوشی (دیتا یا وای‌فای) باید وصل باشد.

## آپدیت‌های بعدی

از نسخه ۱.۱.۰ به بعد، خودِ اپ نسخهٔ جدید را خبر می‌دهد و با یک دکمه دانلود و نصب می‌کند
(امضا ثابت مانده، پس دیگر نیازی به حذف و نصب دوباره نیست).

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| خطای signatures do not match | نسخهٔ قدیمی را کامل Uninstall کنید، بعد نصب کنید |
| دکمه Install خاکستری/غیرفعال | screen overlay (حباب چت/فیلتر نور آبی) را موقتاً خاموش کنید |
| Parse error / خرابی فایل | فایل را دوباره منتقل کنید (حجم باید حدود ۸۳MB باشد) |
| خطای ارتباط با سرور بعد از ورود | اینترنت گوشی + روشن‌بودن Tailscale (در صورت نیاز) را چک کنید |
