# پنل CRM مالک — MA Warehouse (دسکتاپ ویندوز)

داشبورد نظارتی مالک سیستم: نمای کلی، مشتریان، مالی، فعالیت کاربران،
سلامت سیستم و مدیریت کلیدهای API — **فقط‌خواندنی** (به‌جز ساخت/ابطال کلید).

## اجرا (توسعه)

```bash
cd crm_panel
flutter pub get
flutter run -d windows
```

ورود فقط با حساب **مدیر**. آدرس سرور از صفحه ورود قابل تغییر است
(پیش‌فرض `http://127.0.0.1:3000`، ذخیره می‌شود با کلید `crm_server_url`
تا با پنل انباردار قاطی نشود).

## بیلد و نصاب

```bash
flutter build windows --release
ISCC.exe installer\ma-crm-panel.iss   # خروجی: installer\output\Setup-MA-CRM-Panel-v1.0.0.exe
```

## قرارداد امنیت

- همهٔ مسیرها `GET` و فقط با نقش MANAGER؛ تنها نوشتنِ مجاز، مدیریت کلیدهاست
  (همان APIهای موجود `/api/manager/api-keys` — چیز جدیدی اضافه نشده).
- هیچ تغییری در دادهٔ انبار (سفارش/موجودی/کاربر) از این پنل ممکن نیست.
