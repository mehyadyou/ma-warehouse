# داشبورد API — مدیریت کلیدهای دسترسی سیستم‌های بیرونی

داشبورد TypeScript (React + Vite) برای ساخت و مدیریت کلیدهای API عمومی v1.

## اجرا (توسعه)

```bash
cd api_dashboard
npm install
npm run dev        # http://localhost:5180 — proxy به بک‌اند localhost:3000
```

ورود با حساب **مدیر** (شماره موبایل + رمز ۶ رقمی).

## بیلد production

```bash
npm run build      # خروجی در dist/
npm run preview
```

در استقرار واقعی، `dist/` را پشت همان nginx سرو کنید (static) و `/api` را به بک‌اند proxy کنید — همان الگوی nginx-production.conf.example.

## امکانات

- **کلیدها:** ساخت (نام + انتخاب دسترسی‌ها + انقضای اختیاری)، نمایش یک‌بارهٔ کلید خام با کپی، ابطال/فعال‌سازی/حذف، آمار استفاده و آخرین استفاده هر کلید
- **مستندات:** لیست ۹ اندپوینت با اسکوپ لازم، نمونهٔ curl، ساختار پاسخ و جدول خطاها — به‌علاوهٔ `openapi.json` ماشین‌خوان روی خود سرور
- ورود فقط با نقش MANAGER؛ نشست JWT همان سیستم اصلی
