# پنل دسکتاپ انبار MA

این پوشه نسخه دسکتاپ نرم‌افزار انباردار را نگه می‌دارد. رابط کاربری با `PyQt6` ساخته شده و به API بک‌اند پروژه متصل می‌شود.

## اجرای سریع

1. وارد پوشه `desktop` شوید.
2. فایل `Run.bat` را اجرا کنید.
3. در اولین اجرا، وابستگی‌ها از روی `requirements.txt` نصب می‌شوند.

اگر Python نصب نیست:

1. نسخه `Python 3.11+` را از [python.org](https://python.org) نصب کنید.
2. هنگام نصب، گزینه `Add Python to PATH` را فعال کنید.
3. دوباره `Run.bat` را اجرا کنید.

## اجرای دستی

```bash
python -m pip install -r requirements.txt
python app.py
```

## تنظیم آدرس API

به صورت پیش‌فرض برنامه به این آدرس وصل می‌شود:

```text
http://127.0.0.1:3000
```

برای تغییر آن می‌توانید متغیر محیطی `MA_WAREHOUSE_API_URL` را تنظیم کنید.

## بخش‌های اصلی برنامه

- `ورود`: احراز هویت انباردار و بررسی نقش کاربر
- `ورودی‌های اخیر`: گروه‌بندی کارتن‌های ثبت‌شده و چاپ برچسب‌ها
- `تاریخچه تراکنش‌ها`: نمایش آخرین تراکنش‌ها یا فیلتر بر اساس یک تاریخ مشخص
