# پنل انباردار — MA Warehouse (دسکتاپ ویندوز)

جایگزین فلاتری پنل دسکتاپ PyQt6 (`desktop/`). اپ ویندوز نیتیو با همین امکانات:

- ورود انباردار با شماره موبایل و رمز (فقط نقش `WAREHOUSE_KEEPER`)
- **ورودی‌های اخیر**: آکاردئون گروه‌بندی‌شده بر اساس (مدل، محصول|تاریخ ورود) + کارت‌های لیبل با QR — چاپ تکی / گروهی
- **خروجی‌ها**: هر محصولی که از انبار خارج شده (اسکن خروج یا خروج دستی) — فقط انبارِ حسابِ واردشده — با دسته‌بندی (محصول، مدل) و مجموع واحد خارج‌شدهٔ هر گروه
- **چاپ شده‌ها**: فیلتر «لیبل / بیجک» — لیبل‌های چاپ‌شدهٔ کارتن‌ها و بیجک‌های چاپ‌شدهٔ سفارش‌ها (بیجکِ چاپ‌شده از منوی «بیجک» حذف و اینجا نمایش داده می‌شود)
- **تاریخچه تراکنش‌ها**: فیلتر تاریخ شمسی یا آخرین ۵۰ تراکنش
- **بیجک**: گروه‌بندی بر اساس سفارش (هر سفارش یک بیجک) + چاپ برگه‌های بیجک — محتوای هر بیجک بر اساس نحوهٔ ارسال سفارش: باربری (فرستنده، گیرنده، شهر گیرنده، تلفن گیرنده، مدل، تعداد بسته بر اساس نحوهٔ بسته‌بندیِ تعیین‌شده در پنل مدیریت — مثلاً «تعداد کیسه»)، تیپاکس (+ تلفن و کد ملی فرستنده، کد پستی و آدرس گیرنده)؛ سفارش «شهری» بیجک نمی‌سازد
- چاپ لیبل/بیجک روی پرینتر معمولی ویندوز با دیالوگ چاپ سیستم (صفحات ۵۸×۷۷ میلی‌متر، حاشیه صفر)
- ریل‌تایم با Socket.IO: `scanout:done`، `checkin:completed` و `order:created/updated/deleted` (با هر سفارش جدیدِ انبار خودتان، منوی بیجک فوراً به‌روز می‌شود)

## اجرا

```bat
flutter pub get
flutter run -d windows
```

یا بیلد نهایی:

```bat
flutter build windows --release
```

EXE: `build\windows\x64\runner\Release\ma_warehouse_panel.exe`

## تنظیمات

آدرس سرور به‌صورت پیش‌فرض `http://127.0.0.1:3000` است و در صفحهٔ ورود قابل تغییر است (ذخیره‌شده در `shared_preferences`).

## تست‌ها

```bat
flutter test
```

## ساختار

- `lib/core/` — پالت رنگ، کلاینت API (dio)، کلاینت سوکت، مدل‌های لیبل/بیجک
- `lib/screens/` — ورود، شل اصلی (سایدبار + هدر) و چهار تب
- `lib/widgets/` — آکاردئون، کارت لیبل، کارت بیجک، پیش‌نمایش لیبل/بیجک
- `lib/printing/` — تولید PDF (فونت وزیرمتن + QR) و چاپ از طریق `printing`
