# پنل انباردار — MA Warehouse (دسکتاپ ویندوز)

جایگزین فلاتری پنل دسکتاپ PyQt6 (`desktop/`). اپ ویندوز نیتیو با همین امکانات:

- ورود انباردار با شماره موبایل و رمز (فقط نقش `WAREHOUSE_KEEPER`)
- **ورودی‌های اخیر**: آکاردئون گروه‌بندی‌شده بر اساس (مدل، محصول|تاریخ ورود) + کارت‌های لیبل با QR — چاپ تکی / گروهی
- **تکمیل شده‌ها**: کارتن‌های ارسال‌شده با همان گروه‌بندی
- **تاریخچه تراکنش‌ها**: فیلتر تاریخ شمسی یا آخرین ۵۰ تراکنش
- **بیجک**: گروه‌بندی بر اساس سفارش + چاپ برگه‌های بیجک
- چاپ لیبل/بیجک روی پرینتر معمولی ویندوز با دیالوگ چاپ سیستم (صفحات ۵۸×۷۷ میلی‌متر، حاشیه صفر)
- ریل‌تایم با Socket.IO: `scanout:done` و `checkin:completed`

## اجرا

```bat
flutter pub get
flutter run -d windows
```

یا بیلد نهایی:

```bat
flutter build windows --release
```

EXE: `build\windows\x64\runner\Release\ma_warehouse_panel.exe`

## تنظیمات

آدرس سرور به‌صورت پیش‌فرض `http://127.0.0.1:3000` است و در صفحهٔ ورود قابل تغییر است (ذخیره‌شده در `shared_preferences`).

## تست‌ها

```bat
flutter test
```

## ساختار

- `lib/core/` — پالت رنگ، کلاینت API (dio)، کلاینت سوکت، مدل‌های لیبل/بیجک
- `lib/screens/` — ورود، شل اصلی (سایدبار + هدر) و چهار تب
- `lib/widgets/` — آکاردئون، کارت لیبل، کارت بیجک، پیش‌نمایش لیبل/بیجک
- `lib/printing/` — تولید PDF (فونت وزیرمتن + QR) و چاپ از طریق `printing`
